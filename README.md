# 医学生医学科研 AI Agents

面向医学生、医学研究生和生物信息学初学者的三个可复用 Agent Skill：

1. **医学论文阅读 Agent**：从 PDF 或全文中提取研究问题、研究设计、关键结果、局限性和可复现线索，并区分原文事实与推断。
2. **医学论文写作 Agent**：把研究方案、结果和参考文献整理为结构化医学论文草稿，执行引用占位、统计表述和投稿前自检。
3. **医学论文绘图 Agent**：根据研究问题和数据字段规划图表，输出可复现的 R/Python 绘图方案，并检查图注、统计标注和出版质量。

## 目录

```text

scripts/                         轮播图生成脚本

```

## 使用方式

将 `skills/` 下对应的 Skill 目录放入你的 Agent 工作区或 Skills 目录，然后按 `SKILL.md` 中的输入要求提供论文、数据字典、分析结果或绘图需求。三者可以串联使用：

```text
论文阅读 → 论文写作 → 论文绘图 → 投稿前检查
```

## 重要边界

- 输出用于科研学习、研究设计和写作辅助，不替代导师、统计师或临床医生的专业判断。
- 不把 AI 生成内容当作已验证的医学事实；关键结论必须回到原文、数据和可追溯参考文献核对。
- 涉及患者数据时，先完成脱敏与伦理合规检查；不要上传可识别个人身份的信息。
- 本仓库不包含论文原件、患者数据、私有项目数据或 API 密钥。
