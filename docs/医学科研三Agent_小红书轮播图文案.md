## 正文

以前读论文、写Results、整理Figure，常常是三个孤立任务；真正高效的方式，是让它们共用同一条证据链：

PDF/数据 → 论文阅读 → 证据矩阵 → 论文写作 → Figure规划 → 绘图与审查。

我把它拆成3个适合医学生使用的Agent：

1. 论文阅读Agent：帮你看研究设计、Figure和证据边界；
2. 论文写作Agent：把研究问题、真实数据和引用组织成论文结构；
3. 论文绘图Agent：先确定一张图要证明什么，再安排Panel、图型和图例。

最重要的一点：AI可以帮你提速，但不能替你确认原文、数据和统计结果。尤其是医学研究，相关性不能写成因果，小样本模型也不能直接写成临床诊断工具。

建议收藏这组工作流，下一次读到一篇论文时，按“研究问题—研究设计—核心结果—局限性—Figure主张”顺序走一遍，效率会高很多。
